# Revue du dictionnaire illustré

Relecture du 15/11/2026, à partir de [AUDIT_VOCABULAIRE.md](AUDIT_VOCABULAIRE.md).

Corrigés d'après les références : espagnol *la tarta* / *el pastel* et *el portapapeles* ; portugais d'Europe *beisebol*,
*túlipa*, *dónute*, *ioió*, *faláfel* ; arabe *توليب* (tulipe, et non *زنبق*, le lys), *فلامنغو*, *غيتار*, *فلوت*, *تلسكوب*,
*سكوتر بمحرك* ; persan *گاو نر* ; hindi *लेडीबग* ; japonais *カモ* (canard sauvage, comme l'illustration) ; rōmaji *bagetto*, *faraferu*.

Conservés : le mot usuel quand le CLDR décrit le dessin (« dormir » pour « visage endormi », « la mère » pour « famille : femme
et fille ») ; les variantes d'orthographe admises ; les écarts de pinyin (哪儿 se lit *nǎr*) et de lecture kuromoji
(目覚まし時計 *mezamashi-dokei*, 白鳥 *hakuchō*, 料理人 *ryōrinin* sont corrects).
