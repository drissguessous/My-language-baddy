et fille ») ; les variantes d'orthographe admises ; les écarts de pinyin (哪儿 se lit *nǎr*) et de lecture kuromoji
(目覚まし時計 *mezamashi-dokei*, 白鳥 *hakuchō*, 料理人 *ryōrinin* sont corrects).

## Thaï (22/11/2026)

Traductions recoupées avec le CLDR thaï (88 % de concordance). Corrigés : *เลมอน* (citron jaune, comme l'illustration ;
*มะนาว* désigne le citron vert), *นักศึกษา* (étudiant ; *นักเรียน* est l'élève), *มอเตอร์ไซค์* (mot courant pour la moto).
Conservées : les graphies officielles de l'Institut royal (*กระบองเพชร*, *เน็กไท*, *แซกโซโฟน*, *โคอาลา*) quand le CLDR
emploie une variante, et les mots usuels quand le CLDR décrit le dessin. La transcription suit le RTGS (système officiel,
sans tons) ; l'outil automatique disponible (pythainlp, moteur *royin*) produit trop d'erreurs pour servir de référence.
